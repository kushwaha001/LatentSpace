We train a small multilingual tool-calling agent for Indian public transit (Tiny Aya Global, 3.35B; English, Hindi, Marathi, Hinglish; 8 tools including irreversible booking and cancellation on a deterministic mock backend) and study reward hacking in agentic RL with AgentTune and AuditKIT.

AgentTune’s default tool reward (hybrid_prm_reward) scores a correct tool call 0 and no call 1. Trained with it, GRPO learns to never call a tool: 0.00 calls per task and 0% success on every task that needs an action on the held-out test split, while its overall success (0.481) stays close to the distilled student (0.513), because about half of realistic requests are correctly answered by not acting. We therefore report tasks that need a call and tasks that need none separately.

We build an audit-grounded reward from AuditKIT metrics (schema validity, tool-call F1 with semantic argument matching, permission, a multilingual action-aware confirm-before-irreversible check, redundancy). With identical KL-anchored GRPO training, only the reward changed, success on tasks that need a call is 0.023 with the default reward and 0.423 with ours (+0.400 [+0.286, +0.514], p < 0.001). Used as a filter for teacher trajectories, the audit reward cuts unconfirmed irreversible actions from 19.4% to 13.2% (-0.063 [-0.106, -0.024], p = 0.004).

A correct reward ranking is not enough: without a KL anchor, GRPO with our reward also collapsed into silence, because a prompt whose samples are all silent yields zero advantage. DPO followed the imbalance of its preference pairs (unbalanced pairs: over-calling and unconfirmed bookings). Reference-guided distillation from Aya Expanse 32B (reference tool calls replayed on the backend, teacher-written replies, audit-filtered) raised test success from 0.289 to 0.513 (+0.224 [+0.141, +0.309], p < 0.001). Under RL, the audit reward preserves this competence but does not exceed the distilled student. We also found bugs in AgentTune (B1, B15: GRPO never stops a Tiny Aya reply) and AuditKIT (A3: paired_bootstrap returns p ≈ 0.5 for any effect) and fixed them in our pipeline. All models, data, rollouts and logs are public.
